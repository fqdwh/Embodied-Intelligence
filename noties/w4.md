# 指针类 LinkNode

```cpp
// 单向链表节点
typedef struct Node{
    int val;
    Node* next;
}Node;
```

```cpp
class LinkNode{
private:
    Node* begin;
    int length;
public:
    LinkNode() {begin = new Node{0, nullptr}; length = 0;}
    LinkNode(vector<int>& l) {}
    ~LinkNode() {}
    // 插入到第 pos 个节点后 头结点为位置为 0
    void Insert(int val,int pos) {}
    // 按位置删除节点
    void Delete_bypos(int pos) {}
    // 按值删除节点 删除第一个
    void Delete_byval(int val) {}
};
```

* 两种构造函数
* 插入删除
* 合并/反转未完成
